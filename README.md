# 시각적 효과가 타이핑 성능에 미치는 영향

시각적 효과의 ON/OFF에 따라 타이핑 성능에 차이가 있는지 확인한 실험 프로젝트이다.

## 실험

- 조건: 시각적 효과 OFF / ON
- 측정값: 타이핑 속도, 정확도, 소요 시간
- 분석 데이터: 총 30회
- OFF: 15회
- ON: 15회

## 실행

```bash
python3 analysis/analyze.py
```

## 주요 결과

전체 평균에서는 ON 조건의 타이핑 속도가 OFF 조건보다 4.82% 낮았다.

하지만 동일 문장 비교에서는 결과가 일관되지 않아 시각적 효과가 타이핑 성능을 저하시킨다고 단정하지 않았다.

## 폴더

- `data/raw/` : 원자료
- `analysis/` : 분석 코드
- `outputs/` : 분석 결과와 그래프
- `docs/` : 연구 설계 및 판단 기록
- `paper/` : 최종 논문

## 원자료 중복 처리

`typing_results.csv`는 `typing_results_2026-10-06T02-15-22-839Z.csv`와 동일한 파일로 확인되어 분석에서 제외했다.

따라서 실제 분석에는 서로 다른 3개 CSV 파일, 총 30회의 실험 기록을 사용했다.
