AI와 함께 쓰는 첫 논문

시각적 효과가 타이핑 성능에 미치는 영향

컴퓨터 화면에서 발생하는 시각적 효과가 실제 작업 수행에 영향을 주는지 궁금해서, 타이핑 작업으로 범위를 좁혀 직접 실험하고 데이터를 분석한 연구 프로젝트입니다.

작성자: 허민 직접 수행한 비교 실험 데이터 수집: 2026-10-06

01 · QUESTION

무엇이 궁금했는가?

시각적 효과가 타이핑 성능에 영향을 주는가?

처음에는 집중도나 생산성처럼 직접 측정하기 어려운 개념도 고려했습니다. 이후 짧은 기간 안에 직접 데이터를 수집하고 숫자로 비교할 수 있도록 타이핑 속도와 정확도를 중심으로 연구 범위를 좁혔습니다.

가설
시각적 효과가 있는 조건에서는 시각적 효과가 없는 조건보다 타이핑 성능이 낮아질 것이다.

02 · METHOD

어떻게 실험했는가?

조건 시각적 효과가 없는 OFF와 시각적 효과가 적용된 ON을 비교했습니다.
측정값 타이핑 속도, 정확도, 입력에 걸린 시간을 측정했습니다.
실험 데이터 총 30회
OFF 15회 · ON 15회

원자료는 실험 프로그램에서 CSV로 저장했습니다. 중복 파일을 확인한 뒤 동일한 기록이 두 번 집계되지 않도록 제외하고, 서로 다른 3개 파일의 30회 기록을 분석했습니다.

03 · RESULT

실험에서는 무엇이 나타났는가?

타이핑 속도
OFF 594.67
ON 566.00
정확도
OFF 100.00%

평균 소요 시간
OFF 5.79초

타이핑 속도 -4.82%
정확도 -0.53%p
평균 소요 시간 +4.65%
하지만, 가설을 그대로 받아들이지는 않았습니다.

전체 평균에서는 ON 조건의 타이핑 속도가 낮고 소요 시간이 길어 가설과 같은 방향의 차이가 나타났습니다. 그러나 동일 문장을 비교했을 때 결과의 방향이 일관되지 않았습니다. 따라서 이번 실험만으로 시각적 효과가 타이핑 성능을 저하시킨다고 단정하지 않았습니다.

04 · MY JUDGMENT

결과를 보고 무엇을 판단했는가?

동일 문장을 비교했을 때 ON 조건이 더 빠른 문장도 있었고, OFF 조건이 더 빠른 문장도 있었습니다. 특히 문장별 결과가 일관되지 않았기 때문에 전체 평균의 차이만으로 인과관계를 주장하기 어렵다고 판단했습니다.

최종적으로 가설을 수정하거나 결과에 맞춰 바꾸지 않고, 원래 가설은 그대로 유지한 상태에서 “이번 실험에서는 가설이 충분히 지지되지 않았다”고 판정했습니다.

05 · MY WORK

프로젝트에서 내가 한 일

연구 주제를 정하고 측정 가능한 형태로 범위를 좁힌 뒤, 실험을 직접 수행하고 원자료를 확인했습니다. 이후 Python 분석 코드를 통해 조건별 결과를 계산하고 그래프와 CSV 결과를 확인했습니다.
