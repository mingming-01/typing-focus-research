# AI와 나의 판단 기록

## 1. AI에게 도움받은 부분

이번 연구에서 AI는 다음 작업을 보조했다.

- 연구 주제 후보를 정리하는 작업
- 측정 가능한 변수 검토
- 실험 설계 아이디어 정리
- 분석 코드 작성 보조
- 분석 결과를 표와 그래프로 정리
- 논문 구조와 문서 작성 검토

## 2. 직접 수행한 부분

다음 작업은 직접 수행하고 확인했다.

- 최종 연구 주제 선택
- 시각적 효과 ON/OFF 조건 결정
- 실제 타이핑 실험 실행
- 원자료 확인
- 분석 결과 확인
- 그래프 확인
- 최종 결과 해석

## 3. 원자료 확인 과정에서의 판단

원자료 디렉터리의 CSV 파일을 확인한 결과 총 4개의 파일이 있었다.

`typing_results.csv`와 `typing_results_2026-10-06T02-15-22-839Z.csv`가 동일한 내용임을 확인했다.

동일한 실험 기록을 두 번 계산하지 않기 위해 중복 파일을 분석에서 제외했다.

그 결과 분석에는 서로 다른 3개 파일의 총 30회 실험이 사용되었다.

## 4. 분석 결과에 대한 판단

전체 평균에서는 ON 조건의 타이핑 속도가 OFF 조건보다 4.82% 낮았다.

정확도도 ON 조건이 0.53%p 낮았고, 평균 소요 시간은 4.65% 길었다.

따라서 전체 평균만 보면 처음 세운 가설과 같은 방향의 결과가 나타났다.

하지만 동일 문장 비교에서는 ON 조건이 더 빠른 문장이 6개 중 4개였고, 문장별 차이도 일관되지 않았다.

따라서 시각적 효과가 타이핑 성능을 저하시킨다고 단정하지 않았다.

## 5. 최종 판단

이번 연구의 결과는 가설을 충분히 지지하지 못한 것으로 판단했다.

가설과 반대되는 결과도 포함하여 기록했으며, 전체 평균의 차이만으로 인과관계를 주장하지 않았다.

## 6. AI와 나의 판단 3줄

AI는 주제와 실험 및 분석 방법을 정리하는 데 도움을 주었다.

실제 데이터 수집과 원자료 및 그래프 확인은 직접 수행했다.

최종 결론은 AI의 답을 그대로 사용하지 않고 실제 데이터와 분석 결과를 확인한 뒤 결정했다.
