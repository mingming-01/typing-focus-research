# 실험 설계

## 1. 연구 목적

시각적 효과의 유무가 타이핑 성능에 차이를 만드는지 확인한다.

## 2. 실험 조건

| 항목 | OFF | ON |
|---|---|---|
| 시각적 효과 | 없음 | 적용 |
| 타이핑 실험 | 동일한 환경 | 동일한 환경 |
| 측정 항목 | 동일 | 동일 |

## 3. 변경한 조건

시각적 효과의 ON/OFF만 변경했다.

## 4. 고정한 조건

- 타이핑 실험 프로그램
- 입력 방식
- 측정 방법
- 측정 항목
- 문장 데이터
- 결과 저장 형식

## 5. 측정값

- `typing_speed`: 타이핑 속도
- `accuracy`: 입력 정확도
- `elapsed_seconds`: 입력에 걸린 시간

## 6. 반복 횟수

총 30회

- OFF: 15회
- ON: 15회

데이터 수집일은 2026-10-06이다.

## 7. 원자료

실험 결과는 `data/raw/`에 CSV 파일로 저장했다.

원자료 디렉터리에서 총 4개의 CSV 파일을 확인했다.

이 중 `typing_results.csv`는 `typing_results_2026-10-06T02-15-22-839Z.csv`와 내용이 동일한 중복 파일이었다.

중복된 파일을 두 번 분석하지 않도록 해당 파일은 분석에서 제외했다.

분석 스크립트는 `typing_results_*.csv` 패턴을 사용하기 때문에 `typing_results.csv`는 자동으로 분석 대상에서 제외된다.

따라서 실제 분석 대상은 서로 다른 3개 파일의 총 30회 실험이다.

## 8. 분석 방법

`analysis/analyze.py`를 사용하여 원자료를 읽고 조건별 결과를 계산했다.

분석 과정은 다음과 같다.

1. 원자료 CSV 읽기
2. 필요한 데이터 확인
3. ON/OFF 조건별 데이터 구분
4. 조건별 평균과 중앙값 계산
5. ON/OFF 평균 차이 계산
6. 동일 문장 비교
7. 분석 결과 CSV 생성
8. 비교 그래프 생성

## 9. 데이터 검증 방법

분석 실행 시 다음 항목을 자동으로 확인했다.

- 분석에 필요한 필수 컬럼 존재 여부
- 타이핑 속도, 정확도, 소요 시간의 숫자 변환 가능 여부
- `condition` 값이 ON 또는 OFF인지 여부
- 결측값이 있는 주요 측정값 제외 여부
- ON/OFF별 실험 횟수 확인

검증을 통과한 데이터만 조건별 분석에 사용했다.

## 10. 설계 및 데이터 처리 변경 사항

실험 후 원자료를 확인하는 과정에서 동일한 CSV 파일이 중복 저장된 것을 확인했다.

`typing_results.csv`와 `typing_results_2026-10-06T02-15-22-839Z.csv`가 동일했기 때문에 동일한 실험 기록을 중복 집계하지 않도록 `typing_results.csv`를 분석 대상에서 제외했다.

이는 실험 조건을 변경한 것이 아니라 원자료의 중복 기록을 정리한 것이다.

실험 결과 자체는 삭제하거나 수정하지 않았으며, 중복 파일을 제외한 이유를 문서에 기록했다.

## 11. 가설 수정 여부

실험 결과를 확인한 뒤 연구 가설 자체는 수정하지 않았다.

전체 평균에서는 가설과 같은 방향의 차이가 나타났지만 동일 문장 비교에서는 결과가 일관되지 않았기 때문에, 가설을 다른 내용으로 바꾸기보다 원래 가설을 충분히 지지하지 못한 것으로 판정했다.

후속 연구에서는 동일 문장을 ON/OFF 조건에서 균형 있게 반복하고 실험 횟수와 참여자 수를 늘려 문장 난이도와 개인차의 영향을 줄일 필요가 있다고 판단했다.

## 12. 재현 방법

프로젝트 루트에서 다음 명령을 실행한다.

```bash
python3 analysis/analyze.py
```

분석이 완료되면 `outputs/` 디렉터리에 조건별 통계표, 비교 결과 CSV, 그래프가 생성된다.
